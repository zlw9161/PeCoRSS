云台做的三件事What a gimbal actually does What a gimbal actually does云台做的三件事

云台不会让镜头去追一个遥远的东西。它只做三件小事，并且每一帧都重复一次： 测出主体偏离画面中心多少、反向补偿这个偏差、 持续跟随而不是一次性归位。 结果是主体永远稳稳停在画面中央，滑动的是背景。

A gimbal does not chase a distant object with the lens. It repeats three small acts every frame: measure how far the subject drifts from the frame centre, compensate that offset in the opposite direction, and keep following instead of snapping once. The subject stays locked in the centre; the background slides.

测偏差Measure

在 kn×kn 搜索域里，对每个候选算一个「它有多像目标」的置信 s。

Inside a kn×kn search window, score each candidate with a confidence s: how target-like it is.

反向补偿Compensate

按置信做 softmax 得到 aτ,q，加权求和——重心自动挪向目标真正所在的候选。

Softmax the scores into aτ,q and reweight — the mass shifts to where the target actually is.

持续跟随Follow

每一个历史帧独立做一次，再按时间置信 wτ 决定哪几帧值得信。

Repeat independently on every history frame, then let temporal weights wτ decide which frames to trust.

稳定输出Stable out

对齐后的历史与目标帧拼接，被一次 (2,1,1) 卷积收进同一个感受野。

Concatenate the aligned history with the target and fold them into one (2,1,1) receptive field.

02  /  Problem

为什么普通 3D 卷积做不到The rigid receptive field problem The rigid receptive field problem为什么普通 3D 卷积做不到

3D 卷积在时间上也能看到邻帧的 3×3 邻域——覆盖范围并不是问题。 问题在于它的权重是焊死的：不管目标这一帧漂到了窗口的哪个角落， 卷积核都按同一组固定系数把目标和杂波拌在一起。TFoC 的权重则由内容现算， 并且被约束成一个和为 1 的凸组合。

A 3D convolution can already see the 3×3 neighbourhood of neighbouring frames — coverage is not the issue. The issue is that its weights are welded shut: no matter which corner of the window the target drifts into, the same fixed coefficients mix target and clutter. TFoC recomputes the weights from content and constrains them to a convex combination that sums to 1.

自适应Adaptive

Conv3d 是 Σ Wq·xq，W 与输入无关； TFoC 是 Σ aq(x)·xq，权重随目标而动。

Conv3d is Σ Wq·xq with W independent of the input; TFoC is Σ aq(x)·xq, weights that move with the target.

归一化Normalized

Σaq=1 使输出停在特征流形上：搜索域变大也不会稀释能量， 而卷积核变大只会按固定比例掺进更多杂波。

Σaq=1 keeps the output on the feature manifold: a larger search window does not dilute energy, while a larger fixed kernel only mixes in more clutter at fixed ratios.

解耦Decoupled

搜索域 kn 与融合卷积解耦：3×3 → 5×5 融合层参数量不变； 卷积核扩大则参数按 k² 增长。

Search size kn is decoupled from the fusion convolution: 3×3 → 5×5 leaves fusion parameters unchanged; enlarging a Conv kernel grows parameters by k².

时间维Temporal

额外的 wτ 让「这一帧看得清不清楚」参与决策—— 固定卷积核对每个历史帧一视同仁。

Extra weights wτ let “how clear is this frame?” enter the decision — a fixed kernel treats every history frame the same.

诚实的读数。 真实的 aτ,q 只在均匀值 1/n 附近轻微起伏 （本序列上偏离量不超过 ±1.1 个百分点）。这不是 softmax 被温度压平了： 本模型 θ = σspa = 0.9，分数有界 s∈[0,1]，理论上足以把两个候选的 权重拉开 e1/θ ≈ 3.0 倍——余量是够的，它没有去用。 近似均匀是数据给出的答案：同一个 3×3 窗口内 9 个候选的分数最多只差 0.15，权重比因此不超过 1.18 倍。邻域本就连续， 9 个候选看上去几乎一样像目标，硬挑一个反而是过拟合噪声。 这正是云台的本质：持续的微调，而不是大幅度的甩动。 更值得看的是微调发生在哪里：目标点上的分数差是邻域点 / 背景点的 3.0 倍——该拉开的地方它确实拉开了。
An honest reading. Real aτ,q only ripples around the uniform value 1/n (deviation ≤ ±1.1 percentage points on this sequence). This is not a flat softmax caused by temperature: here θ = σspa = 0.9 and scores are bounded s∈[0,1], which is already enough to pull two candidates apart by e1/θ ≈ 3.0× — the headroom is there; the model simply does not use it. Near-uniformity is the answer the data asks for: inside one 3×3 window the nine candidates differ by at most 0.15 in score, so the weight ratio stays ≤ 1.18×. Neighbours are continuous; all nine look almost equally target-like, and forcing a hard pick would overfit noise. That is the gimbal’s nature: continuous fine-tuning, not large swings. More telling is where the fine-tuning happens: the score spread on the target point is 3.0× that of the neighbour / background probes — it opens up where it should.

TFoC 做对了什么
What TFoC got right

把配对好的 (历史, 目标) 沿一条长度 2(t−1) 的轴交错堆叠， 用 stride=2 的 (2,1,k) 卷积逐对做非线性交互—— 打分之前，候选之间先互相看过一眼，而不是各自孤立地被投影。

Paired (history, target) features are interleaved along an axis of length 2(t−1), then a stride-2 (2,1,k) convolution interacts each pair nonlinearly — candidates look at each other before scoring, instead of being projected in isolation.

同时保留候选轴：搜索域 kn×kn 与融合卷积解耦， 空间权重 a 和时间权重 w 都是 Σ=1 的凸组合，输出始终停在特征流形上； 再沿时间轴把对齐后的历史与目标帧拼接，一次 (2,1,1) 卷积收进同一个感受野。

It also keeps the candidate axis: search size kn×kn is decoupled from the fusion convolution; spatial a and temporal w are both Σ=1 convex combinations, so the output stays on the feature manifold; finally the aligned history and target are concatenated along time and folded into one (2,1,1) receptive field.
